`action.mutation.optimistic` and `action.local.set`: a `value_expr` (the primary one or one in `also`) that is
exactly `$item.<field>` or `$route.<name>` sets the field to that value at once (decision
`mutation-item-value`). A picker can then show the tapped row on the screen behind it before the pod answers,
like a picked recipe's id and name on today's Dinner row. Older clients leave such an expression unbound.
